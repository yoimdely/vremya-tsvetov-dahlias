# Время цветов · Георгины

Тестовый каталог с 838 позициями, фотографиями, корзиной и подготовкой заказа для менеджера в Telegram.

Статический сайт: откройте через HTTP-сервер или GitHub Pages. Для Pages выберите Deploy from a branch → main → / (root).

Доступность, доставка и окончательные условия подтверждаются менеджером. Контакты остаются в памяти вкладки, в localStorage сохраняется только состав корзины. Открытие Telegram не подтверждает отправку заказа.

Никаких токенов, исходных таблиц или серверной отправки сообщений в проекте нет.
